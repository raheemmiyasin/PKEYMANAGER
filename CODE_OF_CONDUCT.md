# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers (including people
learning Rust), and keep discussion about the work, not the person. Harassment
of any kind is not tolerated.

## Enforcement

Report unacceptable behaviour to the maintainer privately via
[GitHub](https://github.com/raheemmiyasin). Reports are kept confidential.
Maintainers may remove comments, commits or contributions that break this code,
and may ban repeat or serious offenders from the project.
